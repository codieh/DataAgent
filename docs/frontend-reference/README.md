# DataAgent 前端视觉参考图

本目录包含依据《前端产品需求文档》生成的客户端界面参考图。它们用于确定重构阶段的布局、视觉语言和交互状态，不代表最终像素级实现。

## 页面

1. `01-new-session.png`：首次进入与新会话空状态
2. `02-analysis-workspace.png`：流式分析中的三栏工作区
3. `03-result-exploration.png`：分析完成后的结果探索
4. `04-human-review.png`：人工审核暂停节点
5. `05-settings-diagnostics.png`：设置与连接诊断

## 统一视觉方向

- 暖骨白画布、墨色正文、深森林绿主色、氧化铜强调色
- 瑞士风格无衬线字体搭配等宽技术字体
- 纸张哑光质感、细线分隔、轻阴影和克制圆角
- 桌面客户端原生窗口、动态分栏和可收起检查器
- 普通用户信息优先，SQL、Payload、SSE 事件按需展开
