# DataAgent Visual Assets

Generated with the built-in `imagegen` workflow for the current frontend redesign.

## Brand

- `brand/logo-horizontal.png`: transparent horizontal DataAgent lockup
- `brand/mark.png`: transparent standalone brand mark
- `brand/app-icon.png`: 1024 px desktop application icon
- `brand/app-icon-512.png`: 512 px application icon
- `brand/app-icon-256.png`: 256 px application icon
- `brand/*-source.png`: retained generation sources

The brand direction combines a table/archive index with a geometric `D`. The locked palette is deep forest `#173D32`, oxidized copper `#C56B43`, and warm bone `#F2EFE8`.

## Texture

- `textures/paper-noise.webp`: 512 px warm paper micro-noise texture
- `textures/paper-noise-source.png`: retained generation source

Use the texture sparingly. A low-opacity overlay or `background-blend-mode: multiply` is preferred; it should not reduce text contrast.

## Generation Prompts

### Horizontal Logo

Create one vector-friendly horizontal DataAgent logo. Combine a data table, archive index, and letter D through minimal rectilinear geometry and negative space. Use deep forest with one oxidized copper detail, followed by the exact word `DataAgent`. Avoid AI sparkles, robot heads, chat bubbles, database cylinders, shadows, gradients, and mockup framing.

### Application Icon

Create a square desktop application icon using the same geometric DataAgent mark. Place it on a warm bone matte tile with subtle paper texture and restrained debossed depth. Keep it recognizable at 32 px. Do not include words or extra symbols.

### Paper Texture

Create a uniform warm bone archival paper micro-noise tile with ultra-fine stochastic grain. No objects, borders, vignette, stains, creases, large fibers, or visible repeating motif.
