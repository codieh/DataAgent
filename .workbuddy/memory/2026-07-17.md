# 2026-07-17 工作日志

## 前端 Markdown 渲染修复

**问题**：前端无法正确显示 markdown 格式。AI 回复中的 `#`、`**`、`-`、`` ` `` 等符号被原样显示为纯文本。

**原因**：`screens.tsx` 多处用 `<p>{text}</p>` 直接渲染字符串，React 把字符串当纯文本塞进 DOM，不做 md 解析。

**修复方案**：
- 安装依赖：`react-markdown` + `remark-gfm`（Gfm 扩展支持表格/删除线/任务列表）
- 新建组件：`src/components/Markdown.tsx`，封装 `react-markdown` + `remark-gfm`，带中文教学注释，使用方式 `<Markdown>{mdString}</Markdown>`
- 修改 `screens.tsx` 共 4 处：
  1. 消息内容 `message.content`（用户 + agent 消息都走 md 渲染）
  2. 流式分析总结 `displayedSummary`
  3. 结果页分析总结 `analysis.summary`
  4. Review 页 reason
- 在 `App.css` 末尾追加 `.markdown-body` 样式段：标题/段落/列表/代码/引用/表格/分隔线/任务列表全覆盖，颜色复用主题变量 `var(--forest)`
- `tsc --noEmit` 通过

**学习要点（给前端学习者）**：
- React 的 `{value}` 是纯文本插值，不会解析 HTML/markdown
- 第三方库 `react-markdown` 把 md 字符串解析成 React 元素树，不使用 `dangerouslySetInnerHTML`，天然防 XSS
- `remarkPlugins={[remarkGfm]}` 是给解析器挂插件的标准写法
